# ICE & Deportations 2026: Debate Lesson (Englisch, Oberstufe)

Eine Debattenstunde für den Englischunterricht in der Oberstufe zur US-Einwanderungspolitik und den Abschiebungen durch ICE im Jahr 2026. Die Stunde enthält einen Einstieg mit Quiz, Hintergrundinformationen, Rollenkarten mit Argumenten für verschiedene Positionen, Redemittel für jede Debattenphase und einen Ablaufplan für 45 Minuten bis zur Kompromissrunde.

**Direkt im Browser öffnen:** https://mrbraendt.github.io/eng-q1-ice-debate-oer/

Alles läuft in einer einzigen Datei `index.html`. Die Schriften liegen im Ordner `fonts/`, nur die Icons (Font Awesome) werden von cdnjs geladen.
